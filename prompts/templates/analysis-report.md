# Analysis Report Template

Use this template when generating analysis reports for Azure Developer CLI issues.

## Report Structure

```markdown
# [Analysis Title]

## Summary

Brief overview of key findings and recommendations (2-3 paragraphs).

## Analysis Scope

- Time period covered
- Number of issues analyzed
- Categories included
- Analysis methods used

## Key Findings

### 1. [Major Finding Category]
- Key observation
- Supporting data
- Impact assessment
- Recommendations

### 2. [Major Finding Category]
[Same structure as above]

## Detailed Analysis

### Issue Categories
- Distribution of issues by type
- Trending categories
- Notable patterns
- Category-specific insights

### User Impact
- Affected user segments
- Severity distribution
- Business impact
- Developer experience impact

### Resolution Patterns
- Resolution timeframes
- Common solutions
- Workarounds identified
- Prevention opportunities

## Recommendations

### Short-term Actions
1. [Action item]
   - Impact
   - Effort
   - Priority
   - Owner

### Long-term Improvements
1. [Improvement item]
   - Strategic impact
   - Resource needs
   - Timeline
   - Dependencies

## Next Steps

- Immediate actions
- Follow-up analysis
- Monitoring plans
- Success metrics

## Appendix

### Data Sources
- Issue references
- Time period
- Analysis tools
- Methodology details

### Detailed Metrics
- Raw data
- Calculations
- Trends
- Comparisons
```

## Usage Guidelines

1. **Customization**
   - Adapt sections as needed
   - Add relevant categories
   - Include specific metrics
   - Maintain consistent structure

2. **Data Presentation**
   - Use clear headings
   - Include metrics
   - Add visualizations
   - Link to sources

3. **Recommendations**
   - Be specific
   - Prioritize actions
   - Consider resources
   - Include timeline

Remember: Focus on clarity, actionability, and data-driven insights.
